## Prüfstatus: Definition
- **BESTÄTIGT IM PROJEKT:** bewusste Entscheidung des Viererteams, keine externe Tatsache.
- **PLANANNAHME:** hypothetischer Wert für Schulszenario.
- **UNGEPRÜFTE EXTERNE ANGABE:** im Gespräch erwähnt, Originalquelle/Datum erneut bestätigen.
- **NACHGEWIESEN:** Originalquelle, Datum, Geltungsbereich und ggf. Dokument als Nachweis gespeichert.

| Aussage | „Courtpreis Anbieter X, werktags 18–22 Uhr = ... €“ |
| Quelle | Direktlink zur offiziellen Tarif-/Buchungsseite |
| Stand | Datum und ggf. Tarifzeitraum |
| Gebiet | Berlin, bestimmter Standort |
| Einheit | €/Courtstunde brutto |
| Abgleich | Gegengeprüft von Person ... |
| Status | NACHGEWIESEN oder OFFEN |

## Transparenz
Es ist **besser, einen Wert ausdrücklich als Schätzung anzugeben**, als eine plausible Zahl ohne Primärquelle als Tatsache auszugeben. Besonders bei Schul-Businessplänen zählen Nachvollziehbarkeit und konsistente Berechnungen.
