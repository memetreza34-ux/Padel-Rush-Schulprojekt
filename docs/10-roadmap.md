## Regeln für neue Arbeit
- Jede Zahl: Einheit, Netto/Brutto, Datum, Quelle/Annahme.
- Neue Ideen erst in Projektbrief/Entscheidungslog aufnehmen; nicht stillschweigend bestehende Annahmen überschreiben.
- Alle externen Tools sollen dieselbe Marken- und Preisdokumentation nutzen.
- Jede abgeschlossene Aufgabe bekommt belegbaren Output (Link, Dokument, Bild, Tabelle oder Screenshot).
- Ein **öffentliches** Repository darf keine privaten Daten von Schülern/Interessenten enthalten.
